# Task map

Complete [required reading](read.md) first, then choose the task procedure. Repository policy and existing user authorization govern the work.

| Outcome | Route |
| --- | --- |
| Implement, fix, refactor, experiment, integrate | [Code](../tasks/code.md) |
| Review a diff, branch, PR, or module | [Review](../tasks/review.md) |
| Doc + translate: canonical docs and authorized language pairs | [Docs](../tasks/docs.md), [translation](../tasks/translate.md) |
| Test-compress: reduce a test suite | [Tests](../tasks/tests.md) |
| Explain existing code | [Explanation](../tasks/explain.md) |
| Design, architecture review, survey, or goals | [Design](../tasks/design.md) |
| Queue, status, or coordination | [Manager](../tasks/manager.md) |
| Machine environment | [Environment](../tasks/env.md) |
| Skill-edit: maintain Heaven Style | [Editor](editor.md) |

For ambiguous scope or a handoff, use [work boundaries](work.md). Resume from the canonical queue, current diff, last verified result, and first incomplete acceptance condition. Do not restart settled work or create a second tracker.
