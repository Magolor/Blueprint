# Document

## Summary

Align the canonical document with current evidence, proofread it as a whole, then update authorized translations and projections. Keep the reader’s purpose central.

## Tasks

1. Start [sync](../tasks/sync/README.md): identify canonical claims, source evidence, affected pages, and declared generated or language projections. For a new artifact, choose its owner and audience.
2. [Compose or edit](../tasks/docs/README.md) the canonical artifact using its [writing manual](../tasks/docs/write.md). Apply the accepted behavior in context; put decision history in the devlog.
3. [Proofread](../tasks/proof.md) the source for accuracy, overall emphasis, natural language, links, and useful structure. Compare the edit with the intended claims so brevity does not drop conditions or capability. Reread without the correction request: the page must still serve its original reader and purpose. Verify relevant examples before propagating them.
4. [Translate](../tasks/translate.md) when requested or required by the repository’s existing pair policy. Check translated meaning and required pair parity. Otherwise report relevant translation staleness without expanding scope.
5. Finish [sync](../tasks/sync/README.md): regenerate declared outputs and navigation, run applicable checks, and record concise closeout evidence. Re-proofread affected claims if synchronization changes authored content.

## Acceptance and stopping

The canonical artifact is accurate and understandable, in-scope projections agree, and required checks pass. Identify unverified claims and blocked projections explicitly. Publishing is separate from preparing or validating the artifact.
