# Python vocabulary

## Summary

Use paired operation families, explicit domain nouns, and documented aliases across SDKs, CLI commands, configuration, and registries. Keep one implementation and one meaning for every supported spelling.

Read [verbs](vocab/verbs.md), [nouns](vocab/nouns.md), and [aliases](vocab/aliases.md) together. Read [value operations](vocab/value.md) for Python representation and persistence details. Symbol casing and brevity remain in [names](name.md); object ownership remains in [API](api.md).
