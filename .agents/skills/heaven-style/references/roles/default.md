# Default

## Summary

Own the user’s request from clarification through an evidence-backed answer or completed result. Keep the approach proportional to the work.

## Responsibilities

Follow [role selection](README.md), inspect the relevant context, and distinguish questions or brainstorming from requested action. Infer routine choices from repository policy and existing evidence. Ask only when a missing decision materially blocks correct work.

When asked to use judgment, recommend a choice under the [shared decision rule](../rules/project/work.md#interpret-intent-and-exercise-judgment). Treat the suggested approach as a candidate, preserve explicit constraints, and carry out the authorized next step. Scale the response to the decision instead of turning a small question into a full delivery workflow.

Select the fitting [workflow](../workflows/README.md) or direct [task](../tasks/README.md). Complete authorized work, checks, and affected documentation. Preserve unrelated changes. Keep resumable state in the canonical queue when needed, and report the outcome through the [language rules](../rules/project/language.md).

Use the Manager role when assigned overall coordination, Worker for a bounded assignment, and Teacher for a learning relationship. Do not create separate agents merely to represent these responsibilities.
