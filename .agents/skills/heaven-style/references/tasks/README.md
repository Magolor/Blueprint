# Task map

## Summary

A task produces one bounded result with observable completion. Select your [role](../roles/README.md) first and use a fitting [workflow](../workflows/README.md) when the request spans tasks. A task may run directly for a focused request.

## Task routes

| Result | Task and manuals |
| --- | --- |
| Implement a change, experiment, or integration | [Code](code/README.md); [slices](code/slices.md) for ordered implementation |
| Design an idea, contract, plan, survey, or goals | [Design](design/README.md); [guide](design/guide.md) routes detailed design manuals |
| Inspect a candidate | [Review](review.md) |
| Validate reported issues | [Triage](triage.md) |
| Fix confirmed issues | [Address issues](address.md) |
| Create or revise an artifact | [Compose docs](docs/README.md); [writing](docs/write.md) owns the authoring procedure |
| Check accuracy, clarity, and emphasis | [Proofread](proof.md) |
| Translate an authorized language pair | [Translate](translate.md) |
| Explain a concept or repository behavior | [Explain](explain.md) |
| Reduce redundant tests | [Compress tests](tests.md) |
| Align docs or repository copies | [Sync](sync/README.md) |
| Manage the queue, assign, monitor, integrate, and hand off | [Coordinate](coordinate/README.md); [handoff](coordinate/handoff.md) |
| Edit skill contracts and distribution | [Edit skill](edit/README.md) |
| Repair the machine environment | [Environment](env.md) |

Complete [required reading](../rules/project/read.md), then the selected task and relevant nested manuals. A directory entry does not replace required bodies. Use [work boundaries](../rules/project/work.md) for ambiguity and handoff authority. Resume from the canonical queue, current diff, last verified result, and first incomplete acceptance condition; do not restart settled work or create another tracker.
