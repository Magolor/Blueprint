# Runnable tutorial

## Summary

Explain the end-to-end result, intended reader, and main prerequisite or limitation.

## Prepare

State dependencies, inputs, and isolated resources. Explain external effects
and costs before commands. Use supported public interfaces.

## Run and observe

Give the shortest reproducible sequence, introducing concepts before commands.
Show verified output or success checks and explain their meaning. Mark variable
values. Distinguish source-checkout steps from installed-package use when needed.

## Recover and clean up

Explain likely failures and release only resources created by this tutorial.
Link an optional next experiment if it builds on the completed outcome.

## References

Link the guide, runnable source, and contract. Use an existing tutorial owner
rather than creating a parallel onboarding path.
