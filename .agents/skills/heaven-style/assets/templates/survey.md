# Survey

## Summary

Summarize the question, strongest result, and decision it supports. Use the
repository's report metadata.

## Scope and method

Explain the use case, constraints, comparison criteria, and exclusions. Identify
source dates or versions and how evidence was collected.

## Comparison

Compare options using the same criteria. Distinguish measured results, source
claims, and inference. Add an experiment or cost table only when it helps the
decision, and explain unfamiliar terminology.

## Recommendation and limits

State the preferred option and tradeoffs, or explain why evidence is insufficient.
Name uncertainty, conditions that would change the conclusion, and the owner
of any follow-up. Keep live work in its existing authority.

## References

Link primary sources and inspected snapshots. A survey supplies evidence;
it does not become an accepted decision on its own.
