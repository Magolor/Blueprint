# Handoff

## Summary

Date the snapshot and summarize the verified state, reason for transfer, and
next concrete action. Use the existing handoff owner when one exists.

## Locate and verify

Explain the affected responsibility and link the task, plan, revision, worktree,
and artifacts. Record completed acceptance, actual checks/results, uncommitted
work, and material gaps. Verify current state rather than copying an old log.

## Resume

Identify the first unfinished acceptance condition, prerequisites, blockers, and
observable unblock condition. Link setup authority; record only relevant missing
machine facts and proven recovery traps, never credentials.

## References

Link contracts, environment setup, and verification evidence. Retire or mark the
snapshot stale after transfer. The queue and canonical docs remain authoritative.
