# Security

English | [简体中文](SECURITY.zh.md)

## Summary

Only the current `typescript` and `python` branch revisions receive security triage. This alpha template provides no production support window.

## Report privately

Send a minimal reproduction, affected revision, impact, and safe contact details to the maintainer at `magolorcz@gmail.com`. Do not put undisclosed exploit details or credentials in public issues.

Reports are handled on a best-effort basis. A verified repair or mitigation is documented when available; no response deadline is promised.

## Downstream projects

Replace this contact and support policy when creating your own project. Review your actual dependencies, execution boundaries, and deployment risks.
