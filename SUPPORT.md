# Support

English | [简体中文](SUPPORT.zh.md)

## Summary

Use [GitHub issues](https://github.com/Magolor/Blueprint/issues) for questions, reproducible defects, and documentation gaps. Maintainer responses are best effort.

## Include useful evidence

State the branch, commit or release, operating system, runtime and package-manager versions, exact command, expected result, and actual result. Reduce the example and remove credentials and private data.

For vulnerabilities, follow [Security](SECURITY.md). For changes, follow [Contributing](CONTRIBUTING.md).
