## 0.2.0-alpha.1 — release candidate

- Separate TypeScript and Python starters, each with one SDK and a thin CLI.
- Strict configuration validation, immutable results, and focused behavior and artifact checks.
- Heaven Style with distinct roles, workflows, and tasks; concrete judgment, review, and handoff procedures.
- Corrected Heaven Style with owning-object APIs, five dedicated SOLID principles, paired vocabulary and aliases, and discoverable clean/shared utility rules.
- KV configuration, package-owned static resources, ORM-first SQL, logical error guards, stable-prefix imports, and named-argument guidance.
- Bilingual entry and community documents, citation metadata, and reproducible template archives.

This alpha maintains only the current interfaces. Python spells the package version `0.2.0a1`; the template and skill use `0.2.0-alpha.1`. Publication is recorded by the GitHub prerelease.
