# Heaven Style maintenance

## Summary

Blueprint owns Heaven Style. Edit its canonical tree, keep both product branches identical, and verify the installed result. The skill remains at `0.2.0-alpha.1`.

## Ownership

- `SKILL.md` selects the role, workflow, task, and required reading.
- `references/rules/` owns shared decisions and native language contracts.
- `references/roles/`, `references/workflows/`, and `references/tasks/` separate continuing responsibility, ordered delivery, and bounded procedures.
- `references/design/` owns architecture principles and exact GUI palettes.
- `assets/` contains reviewed resources, templates, and scoped environment notes.
- `scripts/` owns deterministic indexing, installation, dependency scanning, and machine observations.

Use the [editing manual](../../.agents/skills/heaven-style/references/tasks/edit/README.md) before changes. Preserve conditions, examples, and required reading. Keep one owner per rule. Do not package reference repositories or incidental project provenance.

## Verification and installation

Run the index generator and its check mode with a Python environment containing PyYAML. Run both product branch gates after synchronizing the tracked skill tree. Install from the verified source and compare all tracked files with the global copy.

The installer replaces the standard `~/.agents/skills/heaven-style` copy transactionally. It preserves explicitly user-owned local notes and evidence caches. A failed staging check leaves the previous installation usable. The optional Claude plugin bridge points to its managed skill distribution; no duplicate plain skill is needed.

## Review scenarios

Exercise the relevant routes with concrete requests: a bounded manager assignment, an uncertain design suggestion with explicit action authority, a genuine defect with an unsuitable fix, and a source change awaiting installation. Mechanical index and branch checks establish consistency; they do not prove those behavioral outcomes.
