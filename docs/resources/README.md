# Resources

Use this folder for stable architecture, specifications, inventories, and source-of-truth notes.

Create a subfolder only when several durable resources need one owner.

Do not put task state, active checklists, or temporary notes here. Use the queue, plans, reports, or scratch surface instead.

Promote only accepted and reusable conclusions into this folder. Link to an authority instead of copying its content.

[Heaven Style maintenance](heaven-style.md) identifies skill documentation and environment authorities.

[Heaven Style authoring rules](../../.agents/skills/heaven-style/references/tasks/docs/write.md) own PR, issue, comment, document, and report conventions.

Use [release preparation](release.md) for verified template archives and publication order.
