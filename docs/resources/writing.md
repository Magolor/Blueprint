# Writing guidance

## Summary

Use Heaven Style’s authoring procedure and the repository’s native artifact formats. Lead with the reader’s outcome and keep current guidance separate from release history.

Read the [authoring manual](../../.agents/skills/heaven-style/references/tasks/docs/write.md) and select an [artifact template](../../.agents/skills/heaven-style/assets/templates/index.md). Use short, direct English. Preserve technical conditions and uncertainty. Link detailed evidence instead of copying it into every page.

English root documents are canonical. `README.md` is generated from `README.en.md`; authored Chinese counterparts use `.zh.md`. Update paired meaning and line structure together when changing a published pair. LICENSE and CITATION.cff keep their native formats.
