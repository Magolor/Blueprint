# Goals

Use this folder for durable project outcomes. Goals guide tasks but do not store task state.

Add goal files only when the project has a real roadmap. Typical files are `long-term.md`, `mid-term.md`, and `short-term.md`.

## Rules

- Describe an outcome, not an activity.
- Link active short-term goals to their task or plan.
- Update goals when shipped behavior or accepted direction changes.
- Do not copy plan checklists into a goal.
- Do not store live status here.
- Remove completed short-term detail after you record the durable result.
