# Reviews

Use this folder when a review needs a durable audit trail or follow-up task.

A review must include:

- scope and comparison base;
- evidence inspected;
- findings ordered by severity;
- precise file references where useful;
- verification gaps and residual risk;
- acceptance conditions for follow-up.

Use this file name:

```text
docs/reports/reviews/YYYY-MM-DD-<scope>-review.md
```

Use `heaven-style-review` as the suffix for a Heaven Style architecture and code review.
